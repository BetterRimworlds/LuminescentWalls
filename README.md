# Luminescent Walls

Powered architectural walls for RimWorld 1.2–1.6. The walls emit a 'sourceless light', largely as described in the book "The Unincorporated Man" by Dani Kollin and Eytan Kollin.

Luminescent limestone is discovered only as samples in newly generated Ancient Dangers. The Luminescent Walls project cannot be researched normally: repeatedly deconstruct those samples to complete it, unlocking limestone, sandstone, granite, slate, and marble variants. Luminescent Plasteel is a separate, normally researchable project that requires Luminescent Walls and unlocks only the plasteel variant. Existing or already generated dangers are unchanged. Every segment draws 1 W and turns off with the grid.
